Project Overview

This repository contains the code and data used for the research paper titled "Early Parkinson’s Detection Using EEG and CNN-Optimized PSO: A Hybrid Machine Learning Approach." The study aims to develop an automated, low-cost, and reliable diagnostic system for Parkinson's disease (PD) using Electroencephalogram (EEG) signals combined with advanced machine learning techniques.

Authors:
Kamyab Karimi,
Ali Ghodratnama,
Reza Tavakkoli-Moghaddam,
Kamelia Ahmadkhan

Abstract:

Parkinson's disease (PD) is a prevalent neurodegenerative disorder that significantly impacts motor skills. Traditional diagnostic methods are often expensive, invasive, or depend on physician expertise. This study presents a deep learning-based approach for PD detection using EEG signals, involving feature extraction, dimensionality reduction, and classification. The proposed method utilizes a hybrid model combining Convolutional Neural Networks (CNN) with Particle Swarm Optimization (PSO) to achieve a remarkable detection accuracy of 99.5%.

Key Features:

Feature Extraction: Utilizes time-domain features (SWLNGP+CSP) and frequency-domain features (SPV) from EEG data.  
Dimensionality Reduction: Employs an intelligent gray particle swarm optimization algorithm for effective feature selection.  
Classifiers Evaluated: Includes k-Nearest Neighbors (KNN), Random Forest (RF), Support Vector Machine (SVM), and CNN.  
Performance: Achieved the highest detection accuracy of 99.5% using the CNN classifier.

Data Availability

The dataset used in this research is available online at http://predict.cs.unm.edu/downloads.php.
